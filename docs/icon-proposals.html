Full-colour marker bodies

Round two read as generic chips, and the colour was trimmed into invisibility. This round inverts both: the marker is the colour — full-bleed bodies drawn from Ghanaian material culture (kente weave, the state umbrella, wax-print cloth, beadwork), on a saturated palette upgrade. Each direction is shown at true map scale over a simulated basemap at the bottom.

Recommended — A "flat swatch": a different symbol class from the marker, as a key should be. The legend's job is to bind colour → word — the same job every printed atlas key has ever done. Pure colour patch, one hairline, no glyph, no marker anatomy. It also matches the app's existing dot-bullet chip language from the search overlay. B still echoes the marker (defeats the point); C is the quiet variant for dense side-panel lists.
